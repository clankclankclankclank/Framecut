OPEN-SOURCE VIDEO EDITOR

Make every frame count.

Cut on a multitrack timeline, shape the light with GPU effects, and animate the details. Framecut is an independent desktop editor powered by the Concat Rust engine.

THE EDITOR

From rough cut to export.

Work across tracks

Trim and stack footage, titles, audio and adjustment layers. Proxy files make it easier to scrub demanding sources.

Animate in the inspector

Apply an effect from the library, open its controls, then use the keyframe buttons at different playhead positions.

Keep the look through export

Preview and export use the same effect packages. Hardware encoders, including VideoToolbox on supported Macs, are selected when available.

MACOS BUILD GUIDE

Run it locally.

Download the source ZIP to Downloads. Open the ZIP, then run the launcher inside the extracted folder. The first build downloads Cargo dependencies and native libraries.

Download source ZIP Read the full build guide
Terminal · macOS
xcode-select --install
brew install rustup cmake pkgconf ffmpeg
cd ~/Downloads
unzip Framecut-main.zip
cd Framecut-main
bash build_and_run_macos.sh --workspace "$PWD"
